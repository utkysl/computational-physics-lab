# Computational Physics Laboratory

A long-term collection of computational physics experiments
developed as part of my Physics Engineering studies at
Ankara University.

The purpose of this repository is to build practical skills
in numerical methods, scientific programming, simulation,
and computational physics.

## Research Areas

- Numerical Methods
- Computational Physics
- Monte Carlo Simulation
- Particle Physics
- Scientific Computing
- Data Analysis

## Languages & Tools

- Python
- C++
- NumPy
- SciPy
- Matplotlib
- CMake
- Git
